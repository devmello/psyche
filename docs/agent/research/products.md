# Background agents in shipped products

Research for Psyche's background specialists. Compiled 2026-10-25. Every claim is cited inline. "Unverified" marks claims that rest on a single secondary source or on a page that could not be fetched.

## Takeaways for Psyche

- **Sleep beats timeout.** Devin sends idle sessions to sleep and charges nothing while asleep. A new message wakes the session ([Devin usage docs](https://docs.devin.ai/admin/billing/usage)). Psyche specialists should go idle, not die, when they are blocked on the owner, and the budget clock should stop while they wait.
- **Put a hard per-run budget in front of every job.** Zapier caps each agent run at 10 or 40 activities and then "pauses and asks for your input" ([Zapier](https://help.zapier.com/hc/en-us/articles/45697420326285-Zapier-Agents-unexpected-activity-usage)). Perplexity pauses active tasks when the account spending cap is reached ([Perplexity credits](https://intercom.help/perplexity-ai/en/articles/13838041-how-credits-work-on-perplexity)). Hitting a budget should be a pause with a "raise limit" approval, never a silent kill.
- **Show cost live, per job.** After-the-fact cost display drew the loudest complaints; Replit answered with progressive spend updates and an end-of-run summary ([Replit forum](https://replit.discourse.group/t/replit-is-listening-agent-3-updates/7228)). Perplexity shows a live credit counter in the thread ([DataCamp](https://www.datacamp.com/tutorial/perplexity-computer)).
- **Use plan-then-approve for long jobs.** Jules ([docs](https://jules.google/docs/running-tasks)), Devin ([Devin 2.0](https://cognition.com/blog/devin-2)), Replit Plan mode ([docs](https://docs.replit.com/replitai/agent)) and Perplexity Computer, which shows a credit estimate ([DataCamp](https://www.datacamp.com/tutorial/perplexity-computer)), all show a plan before costly work starts. One approval up front, not dozens mid-run.
- **Remember approvals within a job.** Comet asks before it acts on a page and remembers the choice for the rest of the task ([AlternativeTo](https://alternativeto.net/news/2025/11/perplexity-comet-assistant-adds-advanced-multitasking-and-user-permission-controls)). Anthropic's auto mode replaced most prompts with a classifier after reporting that users approve about 93% of prompts (secondary: [TechRadar](https://techradar.com/pro/anthropic-gives-claude-code-new-auto-mode-which-lets-it-choose-its-own-permissions)). Approval tiers should be scoped to the job and remembered.
- **Questions need defaults and expiry.** Devin shows questions with one-tap suggested answers and marks questions it moved past as "skipped" ([Devin release notes](https://docs.devin.ai/release-notes)). A specialist should be able to proceed on a stated default and record that it did.
- **Use a small, fixed status vocabulary.** Zapier uses six statuses: Needs action, In progress, Failed, Cancelled, Completed, Test ([Zapier](https://help.zapier.com/hc/en-us/articles/36818600959501)). "Needs action" maps to the Inbox.
- **Use one notification inbox and back off on repeated failures.** Devin added a notification inbox with All/Unread tabs, and its failure notifications back off after repeats ([Devin release notes](https://docs.devin.ai/release-notes)).
- **Child jobs should inherit a summary, not the whole transcript.** Devin child sessions start with a summary of the parent's context ([release notes](https://docs.devin.ai/release-notes)). Manus sub-agents each get a fresh context and do not talk to each other (secondary: [Fast.io](https://fast.io/resources/manus-ai-agent/)).
- **Refund or flag platform failures automatically.** Manus and Perplexity both restore credits when a task fails on their side ([Manus refunds](https://help.manus.im/en/articles/12992237-how-does-our-ai-agent-s-credit-refund-policy-work), [Perplexity](https://intercom.help/perplexity-ai/en/articles/13838041-how-credits-work-on-perplexity)). Psyche's receipt should separate "spent on useful work" from "lost to errors."
- **Concurrency limits are product decisions.** Jules allows 3, 15 or 60 concurrent tasks ([Jules limits](https://jules.google/docs/usage-limits)). Manus Wide Research runs 20 subtasks at once ([Manus](https://help.manus.im/en/articles/11960169-what-is-wide-research)). People report losing track at two or three parallel threads ([HN](https://news.ycombinator.com/item?id=47573483)). Cap by owner attention, not just compute.
- **Results should be artifacts plus a short summary.** Jules ends with files changed, runtime, line counts, and a "Create branch" button ([Jules](https://jules.google/docs/running-tasks)). Dispatch sends the outcome rather than every step ([Claude support](https://support.claude.com/en/articles/13947068-assign-tasks-from-anywhere-in-claude-cowork)).

## 1. Devin (Cognition)

**Start and scope.** Sessions start from the web app, from Slack by tagging @Devin (Devin then replies in the thread), and from Linear ([Slack docs](https://docs.devin.ai/integrations/slack)). In Linear there are three triggers. Assigning a ticket runs the default playbook. A label such as `!plan` or `!implement` runs the playbook that matches it. A comment mention uses the comment text as the instructions ([Linear docs](https://docs.devin.ai/integrations/linear.md)). Playbooks are reusable task recipes; Knowledge holds org-wide context with optional triggers ([Devin guide](https://docs.devin.ai/use-cases/gallery/learn-about-devin)). Devin 2.0 (April 3, 2025) added Interactive Planning: Devin drafts a plan from the codebase and the user can adjust it before autonomous work starts ([Cognition](https://cognition.com/blog/devin-2)).

**Progress.** The planner keeps a work log. Each step has timestamps, time spent, and a retro graded green, orange or red, corresponding to A, B or C ([Sept '24 update](https://cognition.com/blog/sept-24-product-update)). An October 19, 2026 change made the current step show what Devin is actually doing instead of "Deciding action" ([release notes](https://docs.devin.ai/release-notes)). Devin runs in a cloud VM called "Devin's Machine", and its usage can be monitored from the session page ([2024 release notes](https://docs.devin.ai/release-notes/2024)). In Linear, its todo list syncs to the plan UI ([Linear docs](https://docs.devin.ai/integrations/linear.md)).

**Asking.** Questions arrive in the session thread or channel. September 2026 added clickable answer choices and one-tap suggested answers; questions Devin moved past show as skipped ([release notes](https://docs.devin.ai/release-notes)). An October 2026 notification inbox collects session alerts ([release notes](https://docs.devin.ai/release-notes)).

**Results.** The main output is a PR. Devin fixes review findings on its own PRs before posting them ([release notes](https://docs.devin.ai/release-notes)).

**Steer, pause, cancel.** In Slack, `sleep` pauses Devin until the next message and `EXIT` ends the session ([Slack docs](https://docs.devin.ai/integrations/slack)). Linear has a stop signal ([Linear docs](https://docs.devin.ai/integrations/linear.md)). Queued messages stay editable while Devin is idle, and sleeping sessions can be resumed for 14 days, down from 30 ([release notes](https://docs.devin.ai/release-notes)).

**Parallel.** Devin 2.0 lets users "spin up multiple parallel Devins" ([Cognition](https://cognition.com/blog/devin-2)). The docs say how many can run at once depends on the plan ([usage docs](https://docs.devin.ai/admin/billing/usage)). The pricing page lists "Up to 10" and "Unlimited" concurrent sessions but does not clearly say which plan gets which ([pricing](https://devin.ai/pricing)). Sessions can spawn child sessions ([release notes](https://docs.devin.ai/release-notes)).

**Cost.** Usage is metered in ACUs and grows with the actions Devin takes. Waiting for the user, waiting on tests, and cloning repos do not count, apart from a small VM cost. Session Insights shows the cost of each session to any user ([usage docs](https://docs.devin.ai/admin/billing/usage)). A per-session ACU limit applies to each user message: when it is hit Devin sleeps, and waking it does not reset the session total ([Cognition KB](https://knowledge.cognition.ai/articles/1715208244-for-people-confused-about-session-credit-limits), about a year old). Plans are Free, Pro $20, Max $200 and Teams, with daily and weekly quotas ([pricing](https://devin.ai/pricing)).

**Failure.** After a machine failure, Devin offers "Continue in a new session". Replying in a Teams thread retries a crashed session ([release notes](https://docs.devin.ai/release-notes)).

## 2. Manus

**Start and scope.** You start a task with a chat prompt (Manus is now part of Meta, per [its blog](https://manus.im/ar/blog/manus-preferred-browser)). Scheduled Tasks 2.0 (May 18, 2026) brings schedules to tasks, Projects and Manus-built web apps. A run can continue inside an existing task with its files and results, or start fresh. Runs can keep updating a named artifact ([Manus blog](https://manus.im/en/blog/manus-schedules)).

**Progress.** The agent works on "Manus's computer", a cloud machine with a browser and VS Code ([takeover help](https://help.manus.im/en/articles/11711218-how-can-i-take-over-manus-browser-or-vs-code)). Tasks can be shared by public link ([help](https://help.manus.im/en/articles/11711198-how-can-i-share-a-task)). Unverified: I found no official documentation of a step-by-step "replay" feature. A third-party tutorial describes a live "Execution Stream" whose nodes you can expand ([AI Indigo](https://aiindigo.com/tutorials/getting-started-with-manus-ai-automating-complex-workflows)).

**Asking.** When Manus needs help it "will prompt users to take over" its browser or VS Code, and users can also take over unprompted ([takeover help](https://help.manus.im/en/articles/11711218-how-can-i-take-over-manus-browser-or-vs-code)). Scheduled tasks have a "skip confirmations" setting that controls approval before sending, publishing or posting ([Manus blog](https://manus.im/en/blog/manus-schedules)).

**Parallel.** Wide Research is paid-only and starts automatically when Manus judges a task can be split. It runs 20 subtasks at once, each capped at 50 credits ([Manus help](https://help.manus.im/en/articles/11960169-what-is-wide-research)). Plan concurrency figures differ across third-party sources, for example 20 concurrent tasks on Pro (unverified: [Layer3](https://www.layer3labs.io/guides/manus-ai-pricing)).

**Cost.** Credits pay for LLM tokens, VMs and third-party APIs. Cost depends on "complexity and duration" ([credits help](https://manus.im/help/credits)). The cost of an action is deducted at the start of the next one, so a balance can go negative. New tasks are blocked at or below zero ([credit rules](https://help.manus.im/en/articles/11711097-what-are-the-rules-for-credits-consumption-and-how-can-i-obtain-them)). One example given is $20 Pro with 4,000 monthly credits (same source).

**Failure.** Credits are fully refunded for a "verifiable bug or platform malfunction". Refunds are not given for failures on third-party sites or for tasks that stop at a predefined limit. An AI agent reviews each refund request with read-only access to the execution history ([refund policy](https://help.manus.im/en/articles/12992237-how-does-our-ai-agent-s-credit-refund-policy-work)).

## 3. Perplexity: Comet and Perplexity Computer

**Both names are confirmed.** The Comet background assistant launched October 2, 2025 for Max users ([TechCrunch](https://www.techcrunch.com/2025/10/02/perplexitys-comet-ai-browser-now-free-max-users-get-new-background-assistant/)). Perplexity Computer was announced February 25, 2026 ([Perplexity blog](https://www.perplexity.ai/hub/blog/introducing-perplexity-computer)).

**Comet assistant.** It works in the background while you do other things. A central dashboard works like "mission control" with per-task status. You can step in to approve an email or take over, and it notifies you when it finishes ([TechCrunch](https://www.techcrunch.com/2025/10/02/perplexitys-comet-ai-browser-now-free-max-users-get-new-background-assistant/)). A November 2025 update added parallel actions across tabs and requires approval before it interacts with pages, remembering approvals for the task ([AlternativeTo](https://alternativeto.net/news/2025/11/perplexity-comet-assistant-adds-advanced-multitasking-and-user-permission-controls)).

**Computer: start and scope.** You start by describing an outcome. Computer splits it into subtasks, creates sub-agents, and runs asynchronously. It will "check in if it truly needs you." Perplexity says users can run dozens of Computers in parallel ([Perplexity blog](https://www.perplexity.ai/hub/blog/introducing-perplexity-computer)). For long tasks, a plan preview lists targets, sources, order of work and a rough credit estimate, and work begins only after approval. An activity panel shows progress, and a live credit counter runs in the thread. Since April 17 you can stop one sub-agent or send a follow-up mid-task. One test produced a cited table and memo, exportable to PDF or DOCX ([DataCamp](https://www.datacamp.com/tutorial/perplexity-computer), May 2026, secondary).

**Cost.** Max includes 10,000 credits a month. Pro gets a one-time 4,000-credit bonus. Each thread has a "Usage" dropdown, and an account page breaks usage down by thread. Every Max account has a monthly spending cap, $200 by default and adjustable up to $5,000. When it is hit, active tasks pause and the user is notified with an option to raise it. Credits are restored when a task fails because of an error on Perplexity's side, but not for unwanted results ([help center](https://intercom.help/perplexity-ai/en/articles/13838041-how-credits-work-on-perplexity), June 24, 2026).

## 4. Replit Agent

**Autonomy.** Agent 3 (September 12, 2025) can work autonomously for up to 200 minutes with Live Monitoring. App Testing has Agent test its own work in a real browser and fix what it finds in a reflection loop ([changelog](https://docs.replit.com/updates/2025/09/12/changelog)). An Autonomy Selector with Low, Medium, High and Max levels followed on September 22, 2025 ([Replit forum](https://replit.discourse.group/t/replit-is-listening-agent-3-updates/7228)). The naming has changed since. The current docs list Free, Auto, Power and Max modes, and Plan mode proposes a task list for approval ([agent docs](https://docs.replit.com/replitai/agent)). A Portuguese docs page says Max is gone and offers a "High effort" toggle instead ([PT docs](https://docs.replit.com/pt/features/agent/overview)). I could not settle which is current. Earlier Extended Thinking and High Power toggles cost more ([docs](https://docs.replit.com/replitai/dynamic-intelligence)).

**Checkpoints.** Agent creates checkpoints that capture code, chat context, Agent memory and the dev database. "Rollback to here" reverts to one, and you can roll forward again ([checkpoints docs](https://docs.replit.com/replitai/checkpoints-and-rollbacks)).

**Parallel.** Active background tasks are limited to 1 on Core and 10 on Pro ([agent docs](https://docs.replit.com/replitai/agent)).

**Cost.** Pricing is effort-based, with one checkpoint per request. Per-checkpoint cost appears when you hover the usage icon. Usage alerts and hard budget limits are set on the Billing page. Dashboard data can lag up to 30 minutes ([AI billing](https://docs.replit.com/billing/ai-billing)). Replit estimated about "$10/hr while agent is running autonomously" ([forum](https://replit.discourse.group/t/replit-is-listening-agent-3-updates/7228)).

**Failure.** In July 2025 the agent deleted a production database during a code freeze. Replit responded with automatic dev/prod database separation ([The Register](https://www.theregister.com/2025/07/22/replit_saastr_response/)).

## 5. Zapier Agents (formerly Zapier Central)

**Start and scope.** Zapier Central became Zapier Agents. Users "define triggers and rules" for automated behaviors and connect "live data sources" ([Zapier blog](https://zapier.com/blog/introducing-zapier-ai-agents/), January 2025 per [MIT AI Agent Index](https://aiagentindex.mit.edu/2025/zapier-agents)).

**Progress and log.** Each run appears in Activity with one of six statuses, and you can expand a run to see which actions used activities ([statuses](https://help.zapier.com/hc/en-us/articles/36818600959501), updated October 1, 2026; [usage](https://help.zapier.com/hc/en-us/articles/45697420326285-Zapier-Agents-unexpected-activity-usage)).

**Asking.** There is no dedicated approval primitive. You write "ask for my confirmation through [messaging app] before continuing" into the instructions and give the agent a messaging action. Inside a Zap, you can add a Human in the Loop step instead ([approvals](https://help.zapier.com/hc/en-us/articles/41776074420493)). Approval-by-prompt is only as reliable as the model's instruction following.

**Cost.** Pro costs $50 a month for 1,500 activities, with up to 40 per run. Free gives 400 a month and 10 per run ([pricing](https://zapier.com/l/agents-pricing)). Searches and page visits count. Zapier documents runaway causes: loops between agents and Zaps, triggers that return many records, and processing old records. A run that hits its cap pauses for input, and users get an email warning near their quota ([usage](https://help.zapier.com/hc/en-us/articles/45697420326285-Zapier-Agents-unexpected-activity-usage)).

## 6. Others in brief

**ChatGPT agent / Operator.** Operator was folded into ChatGPT agent on July 17, 2025 ([release notes](https://help.openai.com/en/articles/11794368-chatgpt-agent-release-notes)). According to a search snippet, the help article listed confirmations for high-impact actions, a "watch mode" on certain sites, and caps of 40 requests a month on Plus and 400 on Pro. Clarifications did not count toward the cap. The same snippet says the agent "is no longer available" and points to ChatGPT Work ([help](https://help.openai.com/en/articles/11752874-chatgpt-agent)). Unverified: the page returned 403 when fetched. ChatGPT Work launched July 2026. Users answer its questions and approve important actions, and an auto-review layer checks actions. Scheduled tasks let the user choose when it checks in, and usage is metered so harder tasks consume more ([TNW](https://thenextweb.com/news/openai-chatgpt-work-agent-launch)). ChatGPT Tasks reportedly capped users at 10 active tasks (unverified: [Maginative](https://www.maginative.com/article/openai-launches-scheduled-tasks-in-chatgpt/)).

**Claude: Cowork, Dispatch, scheduled tasks.** Dispatch is a single persistent phone-to-desktop thread. Claude returns the outcome rather than every step and pushes a notification when it is done or needs a go-ahead. There is "no way to start a new thread," the desktop must stay awake, and the feature is in limited beta ([Dispatch](https://support.claude.com/en/articles/13947068-assign-tasks-from-anywhere-in-claude-cowork)). Cowork scheduled tasks run hourly, daily, weekly, on weekdays or manually. Each run is its own session, tasks run remotely unless they need local files, they can be paused, and they have an "approval mode" setting ([scheduled tasks](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork.md)).

**Google Jules.** You pick a repo and branch, then press "Give me a plan". Jules notifies you on completion or when it needs input ([docs](https://jules.google/docs)). An activity feed shows each step with mini diffs. You can chat to steer at any time, pause, or delete the task. The finish summary leads to "Create branch" ([running tasks](https://jules.google/docs/running-tasks)). API sessions auto-approve plans unless `requirePlanApproval` is set (secondary: [review](https://www.danilchenko.dev/posts/google-jules-review/)). Limits are 15, 100 or 300 tasks a day and 3, 15 or 60 concurrent ([limits](https://jules.google/docs/usage-limits)).

**Project Mariner.** Mariner ran up to 10 tasks at once on cloud VMs ([IT Daily](https://itdaily.com/news/cloud/google-rolls-out-project-mariner)). Its landing page reportedly says it was shut down on May 4, 2026, with its technology moved to Gemini Agent ([AInauten](https://news.ainauten.com/en/story/google-macht-project-mariner-dicht)). Unverified: the DeepMind page I fetched did not mention Mariner.

## What users find useful vs confusing

**Useful.** Plan review up front, Devin's chat-with-a-colleague feel ([Answer.AI](https://www.answer.ai/posts/2025-01-08-devin.html)), and checkpoints that undo mistakes ([Replit](https://docs.replit.com/replitai/checkpoints-and-rollbacks)).

**Approval fatigue.** Secondary coverage of Anthropic's figures says users approve 93% of permission prompts. Anthropic's response was a classifier-gated auto mode ([TechRadar](https://techradar.com/pro/anthropic-gives-claude-code-new-auto-mode-which-lets-it-choose-its-own-permissions)). Over-asking also costs money. A Cursor user wrote that "half of my fast requests are wasted" on confirmations ([Cursor forum](https://forum.cursor.com/t/llm-keeps-asking-for-confirmation-to-cost-me-fast-request-quota/99373), June 2025). Gemini Deep Research was "a bit too eager" to start without answering clarifying questions ([Alex Strick](https://alexstrick.com/posts/2025-04-09-first-impressions-of-the-new-gemini-deep-research-with-2-5-pro.html)).

**Runaway cost.** After Agent 3 launched, one user wrote "I blew through $70 in a night." Another said "it charged me $1K" in a week ([The Register](https://www.theregister.com/2025/09/18/replit_agent3_pricing/), September 2025). Replit answered with progressive spend updates and an end-of-run charge summary ([forum](https://replit.discourse.group/t/replit-is-listening-agent-3-updates/7228)). A widely shared Perplexity Computer case reportedly used about 21,000 credits on one codebase scan ([Product with Attitude](https://karozieminski.substack.com/p/save-credits-perplexity-computer)). On r/ManusAiAgent, a popular post was titled "Over 3k Credits Burned For No Work Done" ([GummySearch](https://gummysearch.com/r/ManusAiAgent/)).

**Silent failures.** Answer.AI found Devin "would spend days pursuing impossible solutions" and recorded 3 successes in 20 tasks ([Answer.AI](https://www.answer.ai/posts/2025-01-08-devin.html), January 2025). Replit's agent "invented data" after deleting a database ([The Register](https://www.theregister.com/2025/07/22/replit_saastr_response/)). Devin's 2026 fixes (real current-step text, skipped-question markers) target this ([release notes](https://docs.devin.ai/release-notes)).

**Overlong reports.** A Gemini Deep Research review called the output "quite verbose, just like the OpenAI version" and asked for "more adherence to user requests for short reports" ([Alex Strick](https://alexstrick.com/posts/2025-04-09-first-impressions-of-the-new-gemini-deep-research-with-2-5-pro.html)). Office Watch found Copilot Deep Research reports can be too long and suggests asking for a brief version first ([Office Watch](https://office-watch.com/2025/copilot-deep-research-review-results/)). A Perplexity Computer memo needed about 30 minutes of cleanup ([DataCamp](https://www.datacamp.com/tutorial/perplexity-computer)).

**Losing track of parallel jobs.** One HN user wrote "Two parallel sessions already feel like my limit". Another: "I can only keep 3 threads like this going" ([HN](https://news.ycombinator.com/item?id=47573483)). Addy Osmani recommends time-boxing because it "prevent[s] quiet drift" ([blog](https://addyosmani.com/blog/cognitive-parallel-agents/), April 2026). Devin's inbox and child-session sidebar fixes respond to this problem ([release notes](https://docs.devin.ai/release-notes)). So does Dispatch's choice of a single thread ([Claude support](https://support.claude.com/en/articles/13947068-assign-tasks-from-anywhere-in-claude-cowork)).

## Comparison

|---|---|---|---|---|---|---|

| **Results** | PRs; self-reviewed | Reports, files, updated artifacts | Cited docs, tables, PDF/DOCX | Running app plus checkpoint | Actions in connected apps | Summary + branch/PR |
| **Steer/cancel** | sleep / EXIT, Linear stop, editable queue | Take over | Stop one sub-agent, follow-up | Rollback / roll forward | Cancelled status | Chat, pause, delete |
