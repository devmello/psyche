# S14 plan: Mac helper (`apps/mac-helper`)

Owner: S14. Feature ids: A9, J1–J5, O10 (OS delivery), Q1 (engines), G1 (keychain capability). Later: J6, J7, J9, L1–L5.
Binding inputs: architecture §6, §7, §10; security §4, §12, §13; ADR-001, ADR-009, ADR-014, ADR-016; wire spec v1 (`docs/plans/s00.md`); spike 04 (`docs/spikes/spike-04-ax-snapshot.md`).

## Goal

Turn the S00 handshake skeleton into `Psyche Helper.app` (`com.psyche.helper`): a long-running node that pairs with the Gateway over the NDJSON node socket, declares a capability manifest with side-effect classes, and serves `node.invoke` with streamed `node.event` and a final `node.result` (with a receipt for side effects). Every TCC-gated call on the Mac lives here.

## Steps

1. **Node runtime.** Persisted device identity (data-protection keychain, file fallback for unsigned dev builds). Serve loop: `node.invoke` → `res {accepted}` → handler task → `node.event`* → `node.result`. Reconnect with backoff. Capability registry, a small JSON Schema DSL for `inputSchema`, error mapping onto `ErrorCode` with a machine `details.reason`, receipts.
2. **Permissions (A9).** `permissions.status/request/open_settings` from preflight APIs only (never `TCC.db`), explanations, `x-apple.systempreferences:` deep links, the security §12 order (Accessibility first; Screen Recording only for the vision fallback; Automation per app on first use; Full Disk Access opened in Settings, never requested in code).
3. **Computer use (J1, J2, J5).** Port spike 04's walker into a generic, unit-tested snapshot builder (fake trees in tests, `AXUIElement` live) with helper-held identity refs, visit/emit budgets (6000/400, depth 40 safety cap: the prompt's "depth ≤ 8" is too shallow per spike 04), clipping, pruning, detached focus. Action ladder: semantic AX first, settable check, read-back with backoff, `expect` checks, CGEvent fallback through the HID tap. Tiers (fixed caps + user tiers + "Allow for this session" 30 min), one session lock, global Esc stop via an active event tap.
4. **Screenshots (J3).** ScreenCaptureKit single frames, downscaled to 1372 px wide by default, excluding Psyche, terminals/IDEs and every app whose tier is Off, refused while a secure field is focused; `SCContentSharingPicker` for user-initiated captures.
5. **Apple Events and Shortcuts (J4).** `apps.applescript`, `apps.jxa` in-process (so Automation prompts name the helper), `AEDeterminePermissionToAutomateTarget` preflight per target, `apps.shortcut_run` via `/usr/bin/shortcuts` spawned with responsibility disclaimed.
6. **Keychain (G1, for S06).** `keychain.wrap_key/unwrap_key/store/retrieve/delete` on the data-protection keychain, `[.biometryCurrentSet, .or, .devicePasscode]`, `kSecAttrAccessibleWhenPasscodeSetThisDeviceOnly`, `LAContext` prompts, OSStatus mapping (`-34018`, `-50`, `-25300`, `-128`).
7. **Notifications (O10).** `notify.show` with per-kind categories, actions, text replies, interruption levels, provisional authorization, quiet hours; responses streamed on a long-lived `notify.subscribe` invocation (the protocol has no unsolicited node event yet).
8. **Speech (Q1).** `speech.transcribe_stream` (SpeechAnalyzer + SpeechTranscriber on 26+, DictationTranscriber when vocabulary is given, SFSpeechRecognizer on-device on 15 until spike 03 picks FluidAudio or WhisperKit), microphone or pushed PCM; `speech.synthesize` via `AVSpeechSynthesizer.write` to PCM chunks; Personal Voice opt-in flagged non-commercial.
9. **Bundle and sign.** `scripts/build-app.sh` (hardened runtime, entitlements, optional provisioning profile for the keychain access group), LaunchAgent template, `scripts/tcc-reset.sh`, contributor notes on signing and grant resets.
10. **Docs.** README capability reference, entitlements, permission flows; manual test plans (AX matrix incl. the three spike-04 incidents, Touch ID, notifications, speech); `docs/status/s14.md`.

## Interfaces

- Consumes: `packages/protocol` node frames (`NodeInvokeParams`, `NodeEventParams`, `NodeResultParams`, `NodeCapability`, `Receipt`, `ErrorCode`) through the generated Swift models plus the hand-written `Wire*` envelopes.
- Provides: the capability manifest (`psyche-helper --manifest` prints it). Capability parameter shapes live in each capability's `inputSchema`; a later `protocol:` PR can lift them into `packages/protocol` if the Gateway wants TypeBox types.
- Reads (does not own): `$PSYCHE_HOME/config/computer-use.json` for user tiers (written by the Gateway / desktop settings; format in the README).

## Risks

- **TCC identity.** Grants key on signature + bundle id + path. Unsigned/ad-hoc builds lose grants; the helper must be launched by launchd/LaunchServices, never as a shell child.
- **Data-protection keychain needs an entitlement backed by a provisioning profile.** Without one, `keychain.*` returns `-34018` mapped to `unavailable` with `reason: missing_entitlement`; the device identity falls back to a 0600 file.
- **CI runs macOS 26 SDK (Swift 6.2) while dev machines run 27.** No 27-only API without `#available` + compiler guards.
- **Protocol gaps** (no node-side cancel, no unsolicited node events, no capability param types): worked around locally, requested in `docs/status/s14.md`.
