# Plan — S00 Bootstrap (2026-10-18)

## Goal

One PR series on `ws/s00-bootstrap` that gives every other session a place to work: monorepo scaffold, `packages/protocol` (schemas, frames, method/event registry, node and browser-bridge schemas, codegen, contract interfaces), `packages/testing` (fakes, conformance suite, secret-leak checker skeleton), `packages/db` v0, minimal `apps/gateway`, `apps/desktop`, `apps/web`, `apps/mac-helper`, CI on macOS and Ubuntu, `CONTRIBUTING.md`, `docs/status/s00.md`. Done when `pnpm i && pnpm -w typecheck && pnpm -w lint && pnpm -r test` is green locally and in CI.

## Steps

1. Root scaffold and every package/app skeleton (`@psyche/<name>`, README with owner, placeholder throwing `NotImplementedError`).
2. Protocol domain schemas written by S00 directly (they are the vocabulary everything else uses).
3. Five parallel subagents, each confined to its paths: (a) frames + method/event registry + node + bridge schemas + codegen; (b) contracts + fakes + conformance + secret-leak checker; (c) db v0; (d) CI + templates + CODEOWNERS + CONTRIBUTING; (e) gateway/desktop/web/helper skeletons.
4. Integrate: `pnpm i`, typecheck, lint, tests; fix seams; status file; small conventional commits; push and open the PR.

## Interfaces fixed up front (so the subagents can work in parallel)

- Domain types are exported from `@psyche/protocol` by the names in `docs/04-data-model.md` (`Thread`, `Message`, `Block`, `Run`, `ToolCall`, `ToolSpec`, `Task`, `TaskAction`, `InputRequest`, `ApprovalRequest`, `Grant`, `Receipt`, `Notification`, `CredentialMeta`, `Connector`, `Channel`, `Automation`, `FeedPost`, `Idea`, `Goal`, `LibraryItem`, `Artifact`, `Device`, `NodeCapability`, `UsageRecord`, `Settings`) plus the enums (`SideEffect`, `TargetKind`, `Provenance`, `PermissionMode`, `GrantScope`, `ApprovalKind`, `Decision`, `DeviceScope`).
- WS frames: `{type:"req", id, method, params, idempotencyKey?}`, `{type:"res", id, ok, payload|error}`, `{type:"event", event, payload, seq, stateVersion}`. Errors are `{code, message, details?, retryable?}` with `code` from `ErrorCode`.
- Pairing: `connect` → `{phase:"challenge", nonce, serverOrigin, expiresAt}`; `connect.verify {nonce, signature}` → `{phase:"paired"|"pending"|"denied", ...}`. The signature covers `nonce || platform || deviceFamily || protocolVersion || serverOrigin`.
- `packages/db`: `openDb(path, opts?) → PsycheDb` with `sqlite` (better-sqlite3), `drizzle`, `migrate()`, `close()`; migrations are `migrations/<YYYYMMDDHHMM>_<package>_<desc>.sql`.
- `packages/testing`: one `Fake<Contract>` class per contract, `conformance/<contract>.ts` exporting `describe<Contract>Conformance(factory)`, `secrets.ts` with `registerSecret` / `assertNoSecrets`.

## Risks

- quicktype's Swift output for discriminated unions may be awkward; S14 can refine through `protocol:` PRs. Fallback: a small hand-written Swift emitter.
- better-sqlite3 needs a native build on CI when no prebuilt binary matches; `pnpm` runs its install script (allowed in `pnpm-workspace.yaml`).
- TypeScript 6/7 migration is deferred; the tsconfig avoids every option deprecated in 6.0.
