# Psyche v0.1.0-alpha (draft)

Draft release notes for the first alpha: Milestone 1, "walking skeleton" (docs/08-roadmap.md). Written by INT-3; the tag is cut by the maintainer once PR #60 (CLI, Docker, launchd, release workflow) is merged and the live gates in [tests/acceptance/SCORECARD.md](../../tests/acceptance/SCORECARD.md) pass on a hosted model.

Psyche is an open-source, self-hosted personal agent for macOS and your own Linux server: a Node Gateway (`psyched`) with an agent loop, a Permission Broker that puts every side effect behind an approval card with a receipt, a credential vault that never shows the model a secret, file-based memory you can read and edit, connectors, chat channels and a desktop app.

## What you can do with this alpha

- **Talk to your agent** on the Mac app or in a browser: streaming replies, Markdown, attachments, a follow-up queue, slash commands, a command palette, keyboard shortcuts for everything (⌘/ lists them).
- **Give it work** that outlives the window: tasks run in the background on a durable engine, show up in Activity with every action and receipt, survive a Gateway restart, and reconcile anything that was mid-flight instead of doing it twice.
- **Approve before anything happens**: writes, sends, purchases and new web origins stop at a card that shows the exact arguments, offers scopes (once, this task, this site, always), arms after a short delay, binds to those arguments and expires. Deny is the default; Return never approves.
- **Connect Google** (Gmail, Calendar, Drive) with desktop OAuth: inbox triage, drafts and sends with receipts, calendar planning with free/busy, single-instance edits of a series.
- **Browse** in an embedded browser the agent drives over a CDP bridge: snapshots, forms, carts; new origins ask; checkout stops at a device-only card; "take control" hands you the keyboard and the agent waits.
- **Research** with web search (Brave) and an SSRF-safe fetch that treats every page as untrusted data; briefs go to the Library as Markdown and PDF.
- **Remember**: a workspace of Markdown files (SOUL, IDENTITY, USER, AGENTS, MEMORY, daily notes) the agent reads and writes with provenance, a pre-compaction flush, nightly dreaming as the only writer of MEMORY.md, search under 100 ms, full export.
- **Reach it from Telegram** or WebChat: owner-only private chats run turns; write approvals come with buttons; purchases and credential fills never leave the device.
- **Schedule**: reminders, automations, catch-up after sleep, an Upcoming list.
- **View documents**: PDF, sheets, docs, code and email viewers, a Markdown editor, form fill and flatten, file generators.
- **Dictate** with on-device speech engines and have replies read aloud.
- **Run it on a server**: `psyche` CLI, Docker Compose with hardening, launchd/systemd units, backups (PR #60).

## Security properties checked in CI

Every pull request runs these gates (`.github/workflows/security.yml`, `tests/acceptance`):

- no fixture secret or card / ID / key pattern in any text a model, transcript, log, card or receipt sees;
- the three acceptance scenarios (inbox triage, calendar planning, research brief) end to end on the real agent loop, broker and audit chain with a scripted model;
- the prompt-injection corpus runs in `balanced`, `manual` and `auto` with zero unapproved egress;
- the Gateway is killed at 25 random points across the three scenarios on the real task engine and broker: no duplicate side effect, receipts consistent, re-issued cards, uncertain steps reconciled;
- a hash-chained audit log that verifies;
- an accessibility pass of the main flows: keyboard operation, accessible names on cards, reduced motion.

## Known limitations

- **Models**: Anthropic, OpenAI, Google, OpenRouter and Ollama are wired; the live gates (three runs per scenario per model) have not yet been run on this machine because it has no keys. Spike 05 recommends `qwen3.5:9b` with reasoning off as the local `agent-capable` model.
- **Touch ID approvals** (purchases, credential fills, host exec) are refused until the Mac helper signs its answers (issue #84); denying works.
- **Injection corpus**: the format, validator and runner are in place; the 150 committed cases are still being authored (docs/status/s18.md), so CI runs the worked example today.
- **Standing site grants** are ignored for reads in a tainted turn (issue #69); the research scenario asks once more than it should.
- **Server mode** needs host networking until trusted-proxy identity, passkeys and `PSYCHE_BIND=container` land (issue #79).
- **Thread state** on the model side is in memory: a Gateway restart forgets the agent's recent history for an open thread (issue #52); tasks and approvals are durable.
- The purchase card names the origin, not yet the seller, items and total.

## Upgrading

First release; nothing to upgrade from. State lives under `$PSYCHE_HOME` (default `~/.psyche`): `state/psyche.sqlite`, `workspace/`, `vault.db`, `library/`.
