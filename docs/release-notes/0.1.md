# Psyche v0.1.0-alpha (draft)

Draft release notes for the first alpha: Milestone 1, "walking skeleton" (docs/08-roadmap.md). Written by INT-3. The maintainer cuts the tag once the live gates in [tests/acceptance/SCORECARD.md](../../tests/acceptance/SCORECARD.md) pass on a hosted model from each provider.

Psyche is an open-source, self-hosted personal agent for macOS and your own Linux server: a Node Gateway (`psyched`) with an agent loop, a Permission Broker that puts every side effect behind an approval card with a receipt, file-based memory you can read and edit, and a desktop app. This alpha runs from a source checkout; [docs/guides/](../guides/README.md) say how, and say plainly what is not reachable yet.

## What works in this alpha

- **Talk to your agent** in the Mac app or in a browser: streaming replies, Markdown, attachments, a follow-up queue, a command palette and keyboard shortcuts (⌘/ lists them). The model comes from `PSYCHE_MODEL` and the provider's key variable: Anthropic, OpenAI, Google, OpenRouter or a local Ollama model.
- **Give it work that outlives the window.** Background tasks run on a durable engine. They show up in Activity with every action and receipt, survive a Gateway restart, and reconcile anything that was mid-flight instead of doing it twice.
- **Approve before anything happens.** Writes, sends, purchases and new sites stop at a card that shows the exact arguments and offers scopes (once, this task, this site, this session, always). Cards arm after a short delay, bind to those arguments and expire. Deny is the default; Return never approves.
- **Share folders** with the agent, read only or read and write, from Settings → File access.
- **Browse** in the desktop app's browser pane, which the agent drives over a local bridge: snapshots, forms, carts. A new site asks first, checkout stops at a device-only card, and Take control hands you the keyboard while the agent waits.
- **Remember.** The agent's persona and memory are Markdown files (SOUL, IDENTITY, USER, AGENTS, MEMORY, daily notes) that you edit in Soul & Memory or any editor. The agent's own writes carry their provenance, protected files always ask, and memory search answers in under 100 ms.
- **Schedule.** The agent can set up automations, each approved once, that run unattended and queue any card for you instead of waiting.
- **View documents**: PDF, sheet, doc, code and email viewers and a Markdown editor in the desktop panes.
- **Run it on a server** from source: the `psyche` CLI, Docker Compose with a hardened container, Tailscale or Cloudflare in front, device pairing, and encrypted backups with restore.

## Built and tested, not reachable from the app yet

These exist in the packages, with tests, but the app or the Gateway does not offer them yet ([docs/guides/](../guides/README.md) give the details and any workaround):

- connecting Google (Gmail, Calendar, Drive), IMAP / JMAP mail and 1Password;
- web search;
- creating the Telegram channel (the bot runs once a channel exists);
- the credential vault: nothing can set it up yet, so model keys and connector sign-ins cannot be stored in it;
- dictation and read-aloud;
- nightly dreaming, the persona settings and the pencil, persona presets, incognito threads and git sync of the workspace;
- switching a thread's permission mode (every thread runs in balanced);
- "Export everything" in the app (`psyche export` works);
- Touch ID approvals, which are refused until the Mac helper signs its answers (issue #84); denying works.

## Security properties under test

These run on every push to main and nightly (under the local merge gate, per-PR CI is lint and typecheck; `tests/acceptance`, `.github/workflows/security.yml`):

- no fixture secret or card / ID / key pattern in any text a model, transcript, log, card or receipt sees;
- seven acceptance scenarios end to end on the real agent loop, broker and audit chain with a scripted model: inbox triage, calendar planning and a research brief (Milestone 1), and a PDF form reply, Messages with a voice note, a subscription audit and a weekly review (Milestone 2, scripted ahead of their features);
- the prompt-injection corpus in `balanced`, `manual` and `auto` with zero unapproved egress;
- the Gateway killed at 41 random points across those scenarios on the real task engine and broker: no duplicate side effect, receipts consistent, cards re-issued, uncertain steps reconciled;
- a hash-chained audit log that verifies;
- an accessibility pass of the main flows: keyboard operation, accessible names on cards, reduced motion.

## Known limitations

- **Live gates**: on `anthropic/claude-haiku-5-5`, three runs each, inbox triage and the research brief passed every hard check and calendar planning passed two of three. The local `ollama/qwen3.5:9b` passed the research brief twice in three runs. No OpenAI model has been run yet.
- **Injection corpus**: the format, validator and runner are in place; the 150 committed cases are still being authored (docs/archive/status/s18.md), so the suite runs the worked example today.
- **Server mode** needs host networking until trusted-proxy identity, passkeys and `PSYCHE_BIND=container` land (issue #79). The systemd and launchd units cannot pass a model yet; use Compose or a terminal.
- **Thread state** on the model side is in memory: a Gateway restart forgets the agent's recent turns for an open thread (issue #52). Tasks and approvals are durable.
- **No release artifacts**: no signed DMG, container image or binaries yet.

## Upgrading

First release; nothing to upgrade from. State lives under `$PSYCHE_HOME` (default `~/.psyche`): `state/psyche.sqlite`, `workspace/`, `audit/`, `library/` and, once it is set up, `vault/`.
