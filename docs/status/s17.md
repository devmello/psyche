## M2 — voice memos (Q4 / N11), branch `ws/s17-m2`

- **Works:** `VoiceMemoService.ingest` (recorded audio → transcript → Library `recording` with the transcript as text extract → optional Task) and `fromDictation` (a composer session started with `memo: true`, finished by `VoiceSessionManager.stopMemo`, which hands back the live transcript and the PCM so nothing is transcribed twice). Provenance follows the speaker: owner voice is `owner`; a non-owner channel sender is `untrusted` and any task created from it starts tainted with `{sourceKind: "voice_note", origin, sender}`. The transcript is always content: `analyzeTranscript` lists URLs (never fetched) and flags instruction-like phrasing; the message block quotes the text under a label that names the speaker and says why it is quoted. Auto task creation only on an opening cue ("remind me to…", "todo:", "don't forget…"). 11 tests on the `remind-alice.wav` fixture with `FakeSpeechEngine` and `FakeTaskEngine` from `@psyche/testing`; one more runs when ffmpeg is present (the fixture encoded as OGG/Opus for Telegram and ingested as a channel memo).
- **Widened, additive:** `LibraryWriter.saveAudio` takes optional `kind`, `origin`, `provenance`, `textExtract` (`LibrarySaveInput`), so the Gateway's Library can store recordings with the quarantine rules of data model §9.
- **Not wired:** the Gateway method for the composer (`voice.memo.save`) and `voice.start.memo` are in the `protocol:` PR of this milestone; S01 routes them to `VoiceMemoService.fromDictation`. Channel adapters (S10) call `ingest` with `memoFormatFor(attachment.mime)` and `speaker` from their owner check instead of `transcribeFile` alone, to get the Library item and provenance for free.

## What works (M1)

- **Engine selection** (Q1, ADR-014): Mac node → whisper.cpp → Web Speech (web client only) for transcription; Kokoro → Mac node for synthesis; persona voice `<engine>:<voice>` goes first; cloud voices only when configured and named. Orders are settings; `explain()` reports per-engine reasons.
- **whisper.cpp** via `whisper-cli` (argv, minimal env, temp WAV) or a loopback `whisper-server`; VAD-gated streaming with partials every second of speech; vocabulary and the previous final in `--prompt`. Files are split at pauses because tiny/base drop speech after a long gap (found in the Kokoro → whisper round trip).
- **Kokoro-82M** on an injected `onnxruntime-node` with the `phonemize` G2P (MIT) mapped to misaki symbols; SSML-lite (`break`, `prosody rate`, `say-as characters`). Verified end to end: q8 model synthesizes at RTF ~0.5 on CPU and whisper tiny.en transcribes the result.
- **Cloud voices**: OpenAI `gpt-4o-mini-tts` and ElevenLabs `eleven_flash_v2_5`, 24 kHz PCM; key from a one-shot `ResolvedSecret`, disposed after one header; error bodies are never echoed.
- **Voice notes** (N11): PCM → OGG/Opus 48 kHz mono, MP3, CAF/Opus (in-process remux; ffmpeg cannot mux Opus into CAF); per-channel caps with a bitrate ladder; inbound decode → 16 kHz PCM → transcript. Verified with ffprobe across 4 input formats × 6 channels; Apple `afinfo`/`afconvert` read and decode our CAF.
- **Dictation protocol**: `VoiceSessionManager` (`voice.start/push/stop/cancel`, `voice.segment`/`voice.ended`), device-bound sessions, ordered chunks, chunk and length caps, idle timeout, per-device limit, client-location answer for Web Speech.
- **Read-aloud**: `ReadAloudService` streams `speech.audio` events, saves an MP3 Library item and announces it; message Markdown is flattened and markup stripped so quoted content cannot inject SSML.
- **Models**: checksummed, owner-initiated downloads into `$PSYCHE_HOME/models/` (0700/0600), pinned catalog for whisper.cpp, Silero VAD and Kokoro.

## Independent review

A read-only reviewer found 9 issues on the branch; all are fixed with regression tests in `packages/speech/test/review.test.ts`: Mac-node stream and synthesis calls now carry timeouts beyond the node registry's 60 s default; WAV headers and PCM formats are bounded before any allocation (a 16 KB file claiming 1 Hz had become 262 MB); early-stopped node synthesis and cloud responses are cancelled instead of awaited or left open; a helper failure mid-stream reaches the consumer at once; concurrent `voice.start` calls can no longer exceed the per-device cap; the previous final now reaches whisper's prompt; streaming resampling carries its phase across chunks; an already-aborted signal stops node transcription before any push.

## Requests to other sessions

  - `voice.start {format: AudioFormat (pcm only), language?, vocabulary?: string[] (≤64), threadId?}` → `{sessionId: string | null, location: "node"|"gateway"|"client"|"cloud", engine}`; scope `operator.write`.
  - `voice.push {sessionId, seq: integer ≥ 0, audio: base64 (≤ 512 000 chars)}` → `{}`.
  - `voice.stop {sessionId}` → `{transcript: Transcript}`; `voice.cancel {sessionId}` → `{ok: true}`.
  - Events `voice.segment {sessionId, segment: TranscriptSegment}`, `voice.ended {sessionId, reason: "stopped"|"cancelled"|"timeout"|"error", error?}`, delivered only to the starting device.
  - `speech.readAloud {messageId, voice?}` → `{streamId}` (side-effecting: writes a Library item); events `speech.audio {streamId, seq, audio, format, last}`, `speech.readAloud.completed {streamId, messageId, item: LibraryItem, durationMs}`, `speech.readAloud.failed {streamId, messageId, error}`.

## M3 backlog — Q5 voice mode, branches `ws/s17-q5-protocol`, `ws/s17-q5-speech` / `ws/s17-q5-voice-mode`

- **Protocol** (devmello/psyche#477): `speech.readAloud {save: false}` streams a reply without a Library item; `speech.readAloud.cancel {streamId}` stops one of the caller's streams.
- **Speech:** `ReadAloudService` implements both; `createSpeechHandlers` serves the cancel method, which the Gateway mounts through `SPEECH_METHODS` with no Gateway change.
- **Shell** (`apps/web/src/shell/voice-mode.ts`, `vad.ts`, `components/VoiceModeBar.tsx`; the desktop renders the same shell): `VoiceMode` runs listening → thinking → speaking → listening on one shared microphone. An energy detector ends a hands-free turn after a 0.9 s pause and detects barge-in with a stricter profile. A barge-in session gets the last 600 ms replayed so the first words are kept. Replies are spoken by `GatewaySpeaker` (read-aloud with `save: false`, Web Audio playback, cancel on barge-in) or `BrowserSpeaker` (`speechSynthesis`). A run awaiting an approval or an answer shows "Needs your approval on screen" and nothing is transcribed. The controller never calls `approvals.*`, and a spoken "approve it" is an ordinary owner message.
- **Settings** (off by default): `voice.conversation.enabled`, `.start` (`toggle` hands-free / `push` hold to talk), `.reply` (`gateway` / `browser`), `.bargeIn` (default on), in Settings → Voice & dictation → Voice mode. The composer shows a Voice button only when enabled.
- **Tests:** synthetic audio only, no microphone. Shell: 18 controller, detector and speaker tests plus 3 composer and bar tests. UI: 2 settings tests. Speech: 4 read-aloud stream and cancel tests.
- **Not verified:** a live session with a real microphone and the Mac helper's voice was not run here. Echo cancellation covers the Gateway voice played by the page; with the browser voice on speakers, barge-in can trigger on Psyche's own voice (the setting's hint recommends headphones).
