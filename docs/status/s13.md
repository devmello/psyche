## Stubbed or not done

- OCR and Office conversion need injected providers (no Vision / Tesseract / LibreOffice wiring here).
- Hosted artifact placement needs the Gateway to serve the host page (below).
- Print uses a hidden iframe with the PDF blob; in Electron that depends on the PDF viewer plugin.
- M2 not started: Univer spreadsheet editing, Sandpack React artifacts (self-hosted bundler).
- P2 orchestration lives in S04 (task engine) and S09 (mail reply); the interface it calls is in the
  README ("Documents pipeline"). Form values outside WinAnsi are skipped (`unsupported_characters`)
  until a Unicode font is embedded. The PDF generator has the same WinAnsi limit; `docToHtml` plus
  Chromium print is the full-Unicode path. DOCX charts are data tables.

## Residual risk (artifact sandbox)

CSP cannot close these, so they are listed here and in `core/artifact.ts`:

- **Self-navigation** (`location = "https://x/?data"`). `ArtifactFrame` removes the frame on the
  second `load` and the hosted host page reports `navigated`, but the first request has already
  left. The Chrome test "documents the residual" pins this behaviour.
- **WebRTC ICE** (STUN/TURN to any host) and **DNS prefetch**. The bridge deletes
  `RTCPeerConnection` as defense in depth, but a child `about:blank` frame can restore it.
- **Forged `open-link`**: artifact script can post bridge messages. `ArtifactFrame` honours them only
  while focus is inside the frame and at most once a second, and they open visibly in the browser pane.

Mitigations for the first two belong to the desktop shell (below).

## Independent review

A read-only reviewer subagent checked the diff (12 findings). Fixed with regression tests: forged
`open-link` gating, malformed `cid:` crash plus a viewer error boundary, sheet paging stuck on a
row larger than the budget, frontmatter textarea dropping trailing whitespace, slide text lost
across pages, quarantine gate not resetting per item, PDF handle leak on aborted loads, CSS remote
references not counted, hosted `host-ready` replay, `<area>` links bypassing the bridge, code
selection lost on parent re-render, `onSaved` firing on remote follows, line-diff id wraparound,
empty frontmatter blocks. Timing budgets get a 3x factor when `CI` is set. Not changed: a stale
file-watcher etag can raise a spurious conflict (the compare-and-swap still prevents data loss).

  app's own copies of `pdfjs-dist` assets and import `@psyche/viewers/styles.css`. In Electron,
  cancel subframe navigations away from `about:srcdoc` / the artifacts origin (`will-frame-navigate`)
  and deny `window.open` from artifact frames. Restrict WebRTC for the artifact partition
