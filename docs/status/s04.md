## What works (`packages/tasks`)

- `SqliteTaskEngine` passes `describeTaskEngineConformance`. Leases with a per-claim token, `BEGIN IMMEDIATE` claims (two worker threads on one file never win the same task), expired-lease recovery on claim and in a boot sweep, `uncertain` for unsafe steps interrupted mid-flight (never replayed; `reconcile` settles them), pause / resume / cancel / retry (optionally from a step), input and approval parking, run mode and budgets, browser session and sandbox ownership, plan / checklist updates, keyset-paged lists, `task.updated` / `task.action` events with `stateVersion`.
- `TaskWorkerPool`: claims and runs `AgentLoop` turns, renews leases, derives checkpoints and Activity lines from `tool_call` events, enforces budgets, parks on questions and approvals, watches approvals (approve / deny → re-queue with the decision; expiry → step re-queued; restart re-issue → rebound), stops a cancelled or paused task's turn at once (`AgentLoop.cancel` + `PermissionBroker.revokeRunAuthority`), and writes a turn's result only while its lease is live.
- `createTaskHandlers`: `tasks.list | get | pause | resume | cancel | retry | actions`.
- Tests (46): conformance; two-worker lease race (worker threads + in-process + a fast-check property); expired-lease recovery; crash between an unsafe step's start and its receipt → `uncertain`; cancellation revoking authority mid-step; pause / resume; input request round trip; approval expiry re-queues the step; restart re-issue; budgets; Activity log levels; regression tests for an independent review's findings.

## What works (`packages/scheduler`)

- `SqliteScheduler`: cron (cron-parser 5, IANA timezone, DST-safe), ISO-8601 intervals and one-shot reminders; durable `next_run_at`; one host timer (re-checks at least every 5 min); `wake()` / `tick()` coalesce missed ticks into one run; overlapping runs recorded `skipped`; run history; Upcoming; heartbeat as a system automation; watches (change / text present / price threshold) with transition-only alerts and exponential backoff; events with `stateVersion`; `automations.*` handlers.
- Session targets `main | isolated | named:<id>`, the unattended-run contract in the prompt, scratch notes, runs launched as unattended Tasks, delivery to thread / channel / webhook (through `PermissionBroker`, with a receipt) / none, `NO_REPLY` delivers nothing.
- Tests (29): cron across both DST changes, sleep catch-up coalescing 5 missed ticks into 1 run, the O1 "weekday 7am brief on Telegram after sleep" case, session targets, end to end through the task engine and worker pool, restart re-follow, heartbeat active hours and one-notification rule, webhook allow / deny, watch dedupe (one alert per price drop) and backoff, Upcoming, events, handlers.
