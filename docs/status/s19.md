# S19 status: psyche-node (2026-10-19)

## Works (tested offline)

- Pairing as role `node` with a signed challenge; `paired`, `pending` (code logged, reconnect after the Gateway closes the request's connection) and `denied` (fatal for revoked / key mismatch / role mismatch / protocol mismatch). Identity file 0600, refused when looser.
- `node.invoke` → `accepted`, ordered `node.event`s, exactly one `node.result` validated against the protocol before sending; `node.cancel` honoured; in-flight work aborted when the connection drops; concurrency cap.
- Clock-skew correction from `paired.serverTime` for receipts.
- Transports: WebSocket (no Origin, no token in URL), Unix socket, vsock via bridge process; guest detection; ordered fallback; backoff with jitter.
- Capabilities: `health`, sandbox `exec`, opt-in `exec.host` (approval required, cwd confined), `fs.*` over configured roots (realpath confinement, ro roots, symlink rules), `browser.*` via `PlaywrightDriver`, and a local hub that pairs Psyche Helper and proxies `computer.*`, `apps.*`, `notify.*`, `speech.*`, `keychain.set|delete|status`.
- Installers: LaunchAgent, systemd user unit, guest bootstrap.
- Tests: 68 in `apps/node/test` (fake Gateway with real Ed25519 verification).

## Stubbed / not verified

- vsock never run inside a real VM; manual plan in `apps/node/docs/manual-test-plan.md`.
- macOS guests have no vsock CLI; a bridge command must be configured.
- No credential fill on the node; `exec` output is not streamed live (contract limit).
- Helper hub tested against a TypeScript stand-in, not the Swift helper binary.

- **S14:** `packages/vault/src/slots/helper.ts` calls `keychain.store|retrieve|delete_item`, which the helper does not register (it has `keychain.set|delete|status`). One side should change.

- **S22:** a bundled `psyche-node` binary for the installers (they run `tsx` today).
