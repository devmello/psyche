## What works (M1)

- **Protocol** (devmello/psyche#9, merged): `AGENTS.md` in `PROTECTED_MEMORY_FILES`; `memory.*` methods for the Soul & Memory sheet; `memory.file.changed` and `memory.job.updated` events.
- **Workspace** (H1): first-run copy of S20's `templates/` with `{{token}}` substitution (onboarding values, then the documented defaults), `memory/` and `skills/`, 0700/0600 modes, atomic writes, etag concurrency, path confinement (relative, no `..`/hidden segments, no symlink escape). `BOOTSTRAP.md` is copied only into a fresh workspace and never re-created.
- **Formats**: daily notes `- HH:MM [tag] text` with exact per-entry provenance; `IDENTITY.md` frontmatter parse/serialize; `USER.md` dated directives with supersession in place (H8).
- **Write rules** (security §8): protected files need an approved `memory_protected_write` for agent writes, deletes and renames, never accept `untrusted`; daily notes are append-only for non-owners and forged tags are clamped to the writer; credentials and card numbers are refused everywhere; pause and incognito stop chat-originated writes.
- **Index** (H3): migration with `memory_files`, `memory_chunks`, `memory_fts` (FTS5 + triggers), `memory_claims`, `memory_jobs`, `memory_state`; 400/80 chunker; embeddings via `ModelProvider.embed` (background, incremental); sqlite-vec 0.1.9 when it loads (verified on macOS arm64), brute-force cosine otherwise; ranking per docs/04 §7 with provenance and source filters; incremental reindex by hash; external edits picked up by `fs.watch` plus a periodic rescan.
- **Claims**: `addClaim` refuses owner claims derived from untrusted or system sources (chunk ids, paths, `claim:` chains); `supersedes`; `explain`; `forget` retracts claims, deletes matching daily-note entries and lines in other notes, rebuilds, writes a content-free retraction line and an audit entry with counts.
- **Tools** (H4): `memory_20250818` handler (`view/create/str_replace/insert/delete/rename` over `/memories`), `memory_search`, `memory_explain`, `forget`, `remember` (owner provenance only for the owner's own words in a private turn), `sessions_search` (opt-in, Gateway transcript query); `classifyMemoryCommand` for the broker; outcomes report `provenance: "untrusted"` when they show untrusted content.
- **Flush** (H5): `store.flush(threadId, privateCopy, { taint })` per the S02 contract addition: one tool-less utility-model turn, facts filtered and appended to today's note only (`agent`, or `untrusted:flush:<thread>` when tainted).
- **Context**: `bootstrapContext()` with per-file/`USER.md`/total budgets, truncation and missing-file markers, comments stripped, session kinds (private / delegated / shared).
- **Data API** (H7): `createMemoryHandlers` for all `memory.*` methods; import (ChatGPT, Claude, text, OpenClaw) as staged agent claims with item-by-item confirmation; zip export; reset with dry run; status; pause.
- **Dreaming** (H6): scaffold only (schedule check, eligible-candidate selection, diary entry, job).
- Tests: conformance suite plus format, store, tool, flush, template, importer and handler tests (all green locally).

## Decisions worth knowing

- External edits (Finder, editors, git) are attributed to the owner; untagged daily-note lines stay `agent`. **This assumes the workspace is never a granted folder for the agent's file tools or the sandbox** (otherwise the agent could write there "as the owner"). Request to S05/S21 below.
- Owner writes through `memory.write` need no approval card: a paired device with `operator.write` is the owner.
- Template HTML comments are stripped before injection and indexing (S20 question 5).
- Daily notes injected into the prompt leave out `untrusted` entries by default; they remain searchable (and taint the turn).
- `avatar` defaults to `bundled:default` until S11/S12 name the bundled asset id.
