# Psyche guides

Guides for running and using Psyche as it is on `main` today. Where a design document describes something the code does not do yet, the guides say so.

- [Getting started](getting-started.md): run the desktop app from source, choose a model, onboarding, admin rights, sharing folders, and where Settings live.
- [Approvals](approvals.md): the approval card, scopes, permission modes, device-only approvals, chat approvals, expiry, receipts, revoking grants and untrusted content.
- [Memory and persona](memory-and-persona.md): the workspace files, what the agent may write, editing the persona, pausing, reset and export.
- [Connectors and channels](connectors.md): Google, IMAP and JMAP mail, 1Password, Telegram and web search, and which of them work yet.
- [Server mode](server-mode.md): the Gateway on a Linux server or headless Mac, with Docker Compose, systemd, launchd, Tailscale, pairing, backups and logs.
