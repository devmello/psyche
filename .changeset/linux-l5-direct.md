Direct computer use on Linux: the Linux helper snapshots apps through AT-SPI and acts on them (X11 input and capture, or the Wayland desktop portal with a remembered permission), with the same tools, tiers, password-field protection and approvals as the Mac and Windows helpers. The Gateway gains an optional `surface` on the computer tools, Linux fixed caps and app ids (desktop file ids), starts the helper on demand, and hides the Apple-only tools. Settings › Computer use shows screen and input access with a Revoke button, the X11 and wlroots warnings, and the accessibility note.
