Model signals for work (MW7). The USER.md learner reads the owner's own chat for progress, where they stopped, a new deadline, a handed-in or dropped status and new to-dos; code resolves the item, verifies the quote and decides any status, and writes owner-stated facts cited to the thread. Owner notes get the same work attributes in the extraction pass (progress, stopped at, next step; never a status or a date). The extraction sink gains a fourth method, `suggest`, which can only write an assignment or project suggestion. A work lane (closed assignment form, its own prompt and validator) turns an opted-in sender's notice into suggestions, pending deadline proposals and one-tap asks, never a status or an accepted item. 30 work red-team cases with fakes and recorded Haiku replies.
