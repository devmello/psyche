Everything memory reads other people's text (EM5): the reader returns it only on request and the pass admits a sender only if the People setting includes them (two-way by default; contacts, everyone, or chosen = nobody), never an excluded, blocklisted, bulk or unknown address; their text uses its own pinned prompt, is screened with the display name, and everything learned from it is pending, untrusted and cited to the sender. What a sender says about someone else is a separate switch (`people.aboutOthers`, off). The indexer's HTML-to-text now drops hidden text. Gate: the whole red-team corpus replayed through the real pass against recorded cloud and local replies.
