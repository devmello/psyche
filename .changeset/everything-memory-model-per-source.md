Everything memory: a model per source (EM11). Settings → Everything memory (and the first-run consent) can give any source its own model (None, Cloud or Local, e.g. Messages on Local while Mail stays on Cloud). A local model for one source has its own memory warning and confirmation, and the Gateway refuses to run until every local model in use is confirmed (the confirmation is now a list).
