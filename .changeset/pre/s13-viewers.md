First release of the viewers package: a viewer registry and `ViewerHost`, viewers for PDF (with forms and an XFA warning), spreadsheets, DOCX, slides, images, code, JSON and email, a CodeMirror Markdown editor with rich, source and diff modes and conflict detection, a sandboxed artifact frame, and bounded `extractText` for the agent's file tools.
