Shared connectors: export a command MCP server you set up as a signed `.psyche-connector` file (names only, never a value) and import one from a file or an https link, with the full card, the sandboxed first run, secrets by name and re-approval when an update widens. Author keys can be rotated (the old key signs a statement naming the new one), and signed revocation notices can be made and imported by file or link.
